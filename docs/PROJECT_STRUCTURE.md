# Project Structure

## Overview

This project is a Dart application with Docker support for containerization.

## Directory Layout

```
barber/
├── docs/                    # Documentation
│   ├── PROJECT_STRUCTURE.md # This file
│   └── API.md               # API documentation
├── lib/                     # Dart library code
├── test/                    # Test files
├── pubspec.yaml             # Dart dependencies
├── Dockerfile               # Docker configuration
└── README.md                # Project README
```

## Language Composition

- **Dart**: 94.4% - Primary language for the application
- **Dockerfile**: 5.6% - Container configuration

## Key Components

- **lib/**: Contains the main Dart source code
- **test/**: Unit and integration tests
- **docs/**: Documentation files
- **Dockerfile**: Configuration for Docker containerization
